# Title

### 克隆仓库

git clone https://github.com/afk101/claude-code-proxy.git

### 切换分支

切换到feature/adapt

### 安装依赖

uv venv

source .venv/bin/activate

uv sync



### 配置.env

```markdown
OPENAI_API_KEY="xxx"
# API 基础地址（兼容 OpenAI 格式）
OPENAI_BASE_URL="https://llm.api.zyuncs.com/v1"
# 大模型
BIG_MODEL="copilotcode-13"
# 中模型
MIDDLE_MODEL="copilotcode-13"
# 小模型
SMALL_MODEL="copilotcode-13"

# Optional: Server settings
HOST="0.0.0.0"
PORT="8082"
LOG_LEVEL="INFO"  
# DEBUG, INFO, WARNING, ERROR, CRITICAL

# Optional: Performance settings  
# Minimum tokens limit for requests (to avoid errors with thinking model)
REQUEST_TIMEOUT="90"
MAX_RETRIES="2"


MAX_TOKENS_LIMIT="128000"
# Minimum tokens limit for requests (to avoid errors with thinking model)
MIN_TOKENS_LIMIT="4096"
```

### 授予脚本权限

chmod 777 start_claude_code_proxy.sh

### 试一下能不能启动

./start_claude_code_proxy.sh

### 配置npm link

新建一个终端，根目录执行 npm link

### 修改.zshrc

vim ~/.zshrc

修改里面的配置（主要是为了不要用智效的了）

export ANTHROPIC_AUTH_TOKEN=zyuncs
export ANTHROPIC_BASE_URL=http://localhost:8082
export ANTHROPIC_API_KEY=xxx



改完source ~/.zshrc

 

然后执行

env | grep ANTHROPIC 



看一下是不是成功了



### 日常开发如何使用

打开终端，任意位置都行，执行ccc -auto -d  (开启claude code proxy代理服务)



具体代码仓库执行

claude --permission-mode bypassPermissions   

启动claude code
